# youtube-blocker
If you want to block game sites and doomscroll platforms, use `block.bat`. If you want to unblock them, use `unblock.bat`.

## How to use:
1. Download `block.bat` or `unblock.bat`.
2. Run `block.bat` or `unblock.bat` as Administrator.
3. Enjoy!

## Manual method:
Go to `C:\Windows\System32\drivers\etc\hosts` and open it with Notepad or any text editor to edit website IPs manually.
